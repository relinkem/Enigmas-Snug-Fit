# Enigma's Snug Fit

A Valheim mod for finer building: spin, tilt and nudge pieces while placing them, with snap center.

The full description, images and settings are in [Release/README.md](https://github.com/relinkem/Enigmas-Snug-Fit/blob/main/Release/README.md).
